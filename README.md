# Stitch by Style

เว็บสำหรับออกแบบลายปัก (cross stitch / stitch embroidery) บนผ้า Aida และชิ้นงานพิมพ์ 3 มิติที่เจาะรูไว้ให้ปัก

## ความสามารถ

- **ออกแบบอิสระ** กำหนดขนาดตาราง และชนิดผ้า (Aida 11–20 ct, plastic canvas, ชิ้นงาน 3D)
- **โมเดลแม่แบบ** 8 แบบ (ที่คั่นหนังสือ ที่รองแก้ว พวงกุญแจ ดาว เข็มกลัด การ์ด) หรือ **นำเข้าไฟล์ STL** แล้วระบบตรวจหารูให้อัตโนมัติ
- **เครื่องมือวาด** ดินสอ ยางลบ เทสี ดูดสี เส้นตรง สี่เหลี่ยม สมมาตร เลิกทำ/ทำซ้ำ และแก้ไขรูปทรงชิ้นงาน
- **แปลงรูปภาพเป็นลายปัก** จับคู่กับด้าย DMC อัตโนมัติ ตัดพื้นหลัง และลดจุดเดี่ยว
- **คลังด้าย DMC 437 สี** พร้อมตัวกรองตามโทนสีและตัวหาด้ายที่ใกล้สีที่สุด
- **รายละเอียดลาย** ผู้ออกแบบ ด้าย เข็ม วัสดุ ระดับความยาก และคำนวณจำนวนฝีเข็ม ขนาดชิ้นงาน และปริมาณด้ายให้อัตโนมัติ
- **ส่งออก** พิมพ์/PDF แผนผัง A4, รูป PNG, ลิงก์แชร์ (เก็บข้อมูลไว้ในลิงก์ ไม่ต้องมีเซิร์ฟเวอร์), ไฟล์ JSON และไฟล์ STL สำหรับพิมพ์ 3 มิติ
- **ภาพตัวอย่าง 3 มิติ** ของชิ้นงานพร้อมด้าย

ข้อมูลลายบันทึกไว้ใน localStorage ของเบราว์เซอร์ ควรส่งออกไฟล์ JSON ไว้สำรอง

## พัฒนา

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # สร้างไฟล์ไว้ที่ dist/
```

ใช้ Vite + React + TypeScript + three.js ไม่มี backend จึง deploy เป็นเว็บ static ได้ทุกที่ (เช่น Vercel)

## โครงสร้าง

- `src/pages/` หน้าเว็บ (หน้าแรก สร้างลาย ตัวแก้ไข พิมพ์ ลิงก์แชร์)
- `src/components/` แคนวาส จานสี รายละเอียด ภาพ 3D และหน้าต่างนำเข้ารูป
- `src/lib/` ตรรกะหลัก: แม่แบบ (`templates.ts`), แปลง STL (`stlImport.ts`), สร้าง STL (`plate.ts`), แปลงรูป (`imageImport.ts`), สีด้าย DMC (`dmc.ts`), สถิติ/ปริมาณด้าย (`stats.ts`), แชร์ (`share.ts`)
